# 数学知识点诊断小工具

纯静态、可离线的网页小工具：学生或家长选一个目标知识点（或整章），工具沿先修关系自适应出题，找出**薄弱的根因**，给出**按先修顺序排列的学习路径**，并列出相关的课标条目。无构建步骤、无外部 CDN、无后端；进度只存在浏览器的 localStorage 里。

> 数据（知识点、先修边、课标映射）都是 AI 生成的草稿，未经教师审核，诊断结论仅供参考。

## 运行

在项目根目录（不是 `diagnose/` 里）：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/diagnose/
```

页面通过 `app-assets-base` 指定的目录读取数据，本地是 `../data/`，发布后是 `assets/<SHA>/data/`。完整题库 `questions.json` 是诊断必需数据；网络错误、JSON 损坏、无效题目或某知识点不足两题时，会暂停诊断并提供「重新加载」，保留本机已有进度与草稿。不能直接用 `file://` 打开。知识图谱的详情页还提供「诊断当前知识点」直达入口。

### URL 参数（演示 / 截图 / 分享入口）

| 参数 | 含义 |
|---|---|
| `target=cnm_221` | 直接以某个知识点为目标（可用逗号写多个 id）。没有 `demo` 时，若本机已有同一目标的存档就继续，否则开始新诊断 |
| `chapter=七上 第一章` | 以整章为目标（写法同列表里的“册 + 章号”，URL 里记得编码空格） |
| `demo=1` | 演示模式：由程序模拟一位学生作答并直接到结果页，**不读写存档**。模拟规则：目标两题都错（薄弱）；它的第一个可测先修也两题都错（薄弱，根因）；再往前一个知识点（没有就取目标的另一个先修）第一题错、第二题对（不稳）；其余都一次答对（掌握）——所以结果页能同时看到 掌握 / 不稳 / 薄弱 |
| `step=2` | 与 `demo=1` 合用：只自动答前 2 题，停在第 3 题的出题页 |
| `limit=16` | 本次诊断的题量上限（**按题计**，不写则用设置里的值，默认 16，设置里可调 8–30） |
| `seed=abc` | 固定选题的随机种子：同一目标、同一种子、同样的作答，出的题完全一样（测试、复现用）。不写则每次随机；演示模式默认种子 `demo` |

例：`http://localhost:8000/diagnose/?target=cnm_221&demo=1`

## 使用流程

1. **开始页**：搜索或按「年级 / 册 / 章节」展开列表，点「选为目标」，或点章标题旁的「以整章为目标」。题量上限可在 8–30 之间调（保存在本机）。
2. **出题页**：每题显示知识点、难度（基础 / 标准 / 提高）、题型、这是本知识点的第几题，以及“为什么现在问这个”（目标本身 / 因为某点两题都没通过而回溯 / 第一题没过的复测）。
   - 选择题：点选项再「提交答案」；数值 / 短答题：输入答案后「提交答案」（回车也行）；开放题：可写思路，再「看参考答案并自评」；
   - 「看参考答案并自评」→ 自己点 对 / 不对 / 不会；
   - 「不会」→ 先显示参考答案和解析，再点「下一题」，记为没答对。
   **每题作答后都会显示参考答案和解析**（自动判题时也显示），然后点「下一题」。自动判定后可点「判错了，…」手动改判。还有「撤销上一题」「重新开始」。
3. **结果页**：薄弱根因、**不稳的知识点**、推荐学习路径、路径图（SVG）、已掌握 / 未测列表、相关课标条目汇总、答题记录（含题目、你的答案、参考答案，可逐题更正，更正后整份诊断重新计算）。可「导出 JSON」（含每道题的 id、你的答案、结果、参考答案、解析），或「打印 / 另存为 PDF」（有 `@media print` 样式，打印时自动展开所有折叠项）。
4. 当前题的输入、已选选项和反馈阶段会即时保存为草稿。刷新相同目标 URL 后会恢复；从开始页进入时可点“继续 / 放弃存档”。草稿会核对题目内容，题干、选项或答案更新后不会套用旧草稿，而是提示用户并保留旧草稿供展开核对。出过的题 id 另存在 localStorage（`cnmDiagnose.seen.v1`），下次诊断优先出没出过的题。发现新版时只提示更新，用户手动更新也不会清除存档；隐私模式或禁用存储时无法保证保存。

## 算法

全部在 `engine.js`（UMD：浏览器里是 `window.DiagEngine`，Node 里 `require` 即可；纯函数、无 DOM，会话对象可 JSON 序列化）。UI 只负责调用和渲染。

**图与子图**：`dependencies.json` 里 `topicId` 以 `prerequisiteId` 为先修。目标集合的先修子图 = 目标 + 所有祖先（小学正式知识点和初中知识点都在同一张图里），并做稳定的拓扑排序（先修在前，同层按 `topics.json` 的顺序，保证结果可复现）。每个节点的先修按 **hard 在前、soft 在后** 排序。开始页可以用「全部学段 / 小学 / 初中」筛选。URL 里的旧编号 `cnm_ext_*` 会按 `data/id-aliases.json` 展开成对应的小学知识点再诊断（例如 `?target=cnm_ext_002`）。

**自适应出题**（`createSession` / `nextQuestion` / `nextItem` / `applyAnswer`）维护一个出题栈。**每个知识点最多问 2 题**：

- 初始栈 = 目标按“离目标最近”（拓扑序靠后）排序；所以**先问目标本身**，整章作为目标时先问章末最靠后的点。
- **第一题答对** → 该点记为**掌握**，它的**所有祖先**（含小学节点）记为“掌握（推断）”，不再问。
- **第一题答错或「不会」** → 还没有结论，**同一知识点再出第二题**（同级或更容易，见下「选题」）：
  - **第二题也错 / 不会** → **薄弱**（weak）：把它还没判定的直接先修（hard 先、soft 后）压到栈顶，**深度优先**继续往回走。**只有这种情况才向先修回溯。**
  - **第二题答对** → **不稳**（shaky）：结果页单独标出，并**放进学习路径作为需要补的点**；但**不**向它的先修回溯（默认如此：一次对一次错更可能是粗心或不牢，不足以推断先修有问题；它的先修保持「未测」，除非别处的回溯、或后续目标的答对把它们判定了）。如果以后想改成「不稳也回溯」，改 `applyAnswer` 里 `nth === 2 && result === 'correct'` 那一支即可。
- 如果一个知识点只有 1 道题（或第二题已无可出的题），第一题答错就直接判薄弱。
- 已判定（掌握 / 不稳 / 薄弱）的点不会重复问；直接作答的判定不会被“推断掌握”覆盖。
- 小学知识点与初中知识点一样出题（每个知识点最多 2 题）。图里已经没有不出题的 `cnm_ext_*` 节点。
- 题量上限按**题**计（不是按知识点），默认 **16**，可调 8–30。结果页每次最多追加 4 题，最多追加到 60 题；接近上限时按剩余额度显示，达到上限后不再显示无效的追加按钮。到上限时剩下没测的点标为「未测」；如果某个知识点只答了第一题（答错）就到上限，没来得及复测，会暂按薄弱处理并在结果页提示「未复测」。

**选题**（`pickQuestion`，纯函数，由会话里的 `seed` 决定）：

- 用 mulberry32 伪随机数，随机数只取决于 `(seed, 知识点, 第几题)`，所以**同一种子、同样的作答 → 出题完全相同**，`replay`（刷新恢复、撤销、更正）也因此一致。URL 参数 `seed=` 可固定种子；不写则每次会话随机生成并存进存档。
- **第一题**：在本次会话没出过的题里随机；优先**没出过**的（已出过的题 id 记在 localStorage，创建会话时作为 `avoid` 传给引擎；全都出过就允许重复）；有非 advanced 的题时不抽 advanced。
- **第二题**：**同级或更容易，优先 basic，其次与第一题同难度**，再其次其它更容易的，最后（没有别的选择时）才出更难的；难度优先于「没出过」，同一难度档里仍优先没出过的。
- 本次会话里同一道题不会出第二次。

**结果**（`summarize`）：

- **根因** = 判为薄弱、且它的直接先修里**没有**薄弱点的节点（先修里是「不稳」的不算薄弱）。若它的先修里还有题量用完没测到的点，会标出“真正的根因可能更靠前”。手造图里如果还有没有诊断题的节点，结果里会单独标出这些先修；现行数据里小学知识点都有题。
- **不稳** = 第一题错、第二题对的点（`summary.shaky`）。
- **学习路径** = 从所有根因**和不稳的点**出发、沿“被依赖”方向可达的、在先修子图内的节点，去掉已掌握的，**按年级从低到高排列**（同一年级里保持拓扑序，先修在前）。薄弱点和不稳的点一定都在路径上；路径里的「未测」点建议先自查。答错初中题会一路问到小学。
- **路径图**（`layout`）：画“路径 ∪ 目标 ∪ 根因 ∪ 实际问过的点”，边取这些点上可达关系的传递约简（中间省略了未画出的点时画虚线），按最长路径分层、重心法减少交叉，先修在上、目标在下。

**一致性**：`replay(graph, targets, answers)` 由作答记录重建会话，保留记录中的原题目 ID；`replayWithReport` 还返回被移除记录的下标和原因。更正某题后，只沿用仍符合新诊断流程的作答，不再适用的后续记录会移除并提示用户，未完成部分重新提问。旧存档没有题目 ID 时，仍可按原种子重建。

## 判题规则

按题型判（`judgeQuestion(question, userText)`），只在**可靠**时给出对 / 错，其余让用户对照参考答案自评（返回 `correct` / `wrong` / `manual`）：

- **choice**：先匹配有效选项字母（含全角、小写和常见括号写法），再匹配唯一的选项文字。选项文字是 `x`、`t` 等字母时，只要它不是该题的有效选项编号，也可正常识别；有效编号与文字冲突时优先按编号判断。界面里选择题是点选项。
- **numeric**：用下面的数值规则；`answer` 里有多个答案时，带 `unordered: true` 才顺序无关，否则**按顺序**逐项比较；`accept` 里的等价写法也算对。题目可用 `variables` 明确变量与参考值的对应，例如 `['x','y']` 对应 `3，2`。写了变量标签时会按标签匹配，不能混淆或重复变量；未提供变量契约时，不会擅自忽略用户写的标签。
- **short**：规范化后与 `answer` 或 `accept` 精确匹配，或保持顺序的可靠数值／坐标等价时判对。文字、代数式和有序结果不再当作无序集合重排；其余不匹配写法交给自评。
- **self**：一律自评。
- 引擎独立调用仍兼容 legacy 题，但网页不会在题库加载失败时进入此模式。

下面是数值 / 文本的通用规则（`judgeAnswer`）：

规范化（两边都做）：全角转半角（NFKC：`１/２`→`1/2`，`，；：（）－` 等）、统一空白和中文标点、`×÷`→`*/`、`²`→`^2`、角度符号、`≦≧`→`≤≥`、“答：”前缀、带分数 `1 1/2` / `1又1/2`。千分位只在明确的单数值参考答案下识别，`40，130` 等多答案不会再合并为一个整数。阶乘号、重复小数点、空答案分隔项和错误单位尾缀不会被清掉后当成正确数值。

比较规则：

1. 规范化后文本完全相同 → 对。
2. 拆成多个答案（按 `, ; 、 ，` 以及“和 / 或 / 与 / 及”拆，括号里的逗号不拆，所以坐标 `(1,2)` 是一个答案），**顺序无关**地比较：`-3 和 -1/2` ≡ `-1/2，-3`。
3. 每个答案若能安全解析为数值，就用**精确有理数**比较（整数、小数、分数、百分数、带分数、带正负号或括号）：`1/2` ≡ `0.5` ≡ `2/4` ≡ `50%`；`1/3` ≢ `0.333`。坐标 `(a,b)` 逐项比较。
4. 变量名：参考答案或题目的 `variables` 明确变量时，写了标签就按变量对应，不依赖标签的书写顺序；没有标签则按参考值顺序作答。没有变量契约的额外标签交给自评，重复或混淆变量不会被忽略后直接判对。
5. 单位：别名等价（`米`=`m`，`平方米`=`m²`，`度`=`°`…）。题目可用 `unit` 指定已核实的期望单位，纯数字输入仍可接受，明确填错受支持的单位会判错。参考答案和题目均未指定单位时，额外输入的单位不会直接算对，改为对照答案自评；不自动进行跨单位换算。
6. 双方都是数值但不等价 → 错；**代数式、文字、其它写法** → 只在规范化后完全相同时判对，否则**不下结论**，显示参考答案让用户自评（例如 `y=3x+2` vs `y=2x+3` 也交给人，因为 `y=(x-2)²-1` 与 `y=x²-4x+3` 这类等价写法无法可靠判断）。

界面上始终提示：自动判题是近似的，以参考答案为准，可以手动更正。

## 导出 JSON 的结构

`version: 2`、`label`、`targets`、`limit`、`seed`、`asked`、`finished`、`limitReached`、`answers`（每题：`order`、`topicId`、`questionId`、`difficulty`、`type`、`prompt`、`userAnswer`、`result`、`referenceAnswer`、`explanation`）、`weakRoots`（含掌握标准、课标 id、未测先修）、`path`（带序号、状态）、`weak`、`shaky`、`mastered`（直接 / 推断）、`untested`、`standards`（id + 原文）。

## 局限

- **每个知识点最多 2 题**：题库每个知识点 4–5 题，由 AI 生成、未经教师审核（核验方法与局限见 [../docs/questions.md](../docs/questions.md)）。两题仍然很少：选择题有 25%–33% 的蒙对概率，一对一错的「不稳」只是提示，结果是“线索”不是“结论”。重测多次会遇到重复的题。
- **不稳不回溯**是一个设计取舍：第一题错第二题对时不继续追查先修，可能漏掉真正的薄弱先修；它们会在路径里标出，建议自查。
- 答对一个点就推断它的所有祖先已掌握，依赖先修图的准确性；先修边是 AI 生成、未经教师审核的草稿。
- 小学和初中在同一张图上。题量上限默认 16，一次诊断往往问不到一条很长的先修链的最前面；把上限调大，或对结果里的「未测」点再诊断一次，才能走到一年级。旧链接 `cnm_ext_*` 只跳到别名文件里的代表知识点，不是该主题的全部小学知识点。
- 判题只覆盖数值、分数、坐标、多答案和带单位的简单答案；代数式、文字题、证明题一律自评。`2/4` 这类未约分的写法也会被判对（只比数值）。
- 薄弱点只由“答错 / 不会”决定，不区分概念性错误和计算失误。
- 路径图是简单的分层布局，跨多层的长边可能从别的节点后面穿过；节点很多时需要横向滚动。
- 进度只存在当前浏览器的 localStorage，换浏览器或清除数据就没了；隐私模式下可能无法保存。
- 页面已适配手机和平板；无障碍（键盘 / 读屏）仍主要依靠基本语义标签，实机和辅助技术体验需要继续验证。
